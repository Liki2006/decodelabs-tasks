# E-Commerce Sales & Customer Behaviour Analysis

## 📌 Project Overview

This project is an end-to-end data analytics project focused on understanding **e-commerce sales performance, customer behaviour, product performance, and marketing effectiveness**.

The project was completed through four stages:

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. SQL Business Analysis
4. Power BI Dashboard

The objective was to transform raw e-commerce data into meaningful business insights and present them through an interactive dashboard.

---

## 🎯 Business Problem

The business needs to understand its sales performance, customer purchasing behaviour, product performance, and marketing channels in order to make better data-driven decisions.

This project answers questions such as:

- Which products generate the most revenue?
- Which referral sources bring the most customers and revenue?
- How do order volumes change over time?
- What is the average order value?
- Which payment methods are commonly used?
- What factors are associated with higher order values?

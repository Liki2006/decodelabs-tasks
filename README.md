# E-Commerce Sales & Customer Behaviour Analysis

## 📌 Project Overview

This project is an end-to-end data analytics project focused on understanding **e-commerce sales performance, customer behaviour, product performance, and marketing effectiveness**.

The project was completed through four stages:

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. SQL Business Analysis
4. Power BI Dashboard

The objective was to transform raw e-commerce data into meaningful business insights and present them through an interactive dashboard.

---

## 🎯 Business Problem

The business needs to understand its sales performance, customer purchasing behaviour, product performance, and marketing channels in order to make better data-driven decisions.

This project answers questions such as:

- Which products generate the most revenue?
- Which referral sources bring the most customers and revenue?
- How do order volumes change over time?
- What is the average order value?
- Which payment methods are commonly used?
- What factors are associated with higher order values?

📊 Key Business Insights

The analysis helped identify:
The average customer order value is approximately ₹1,053.97.
Higher unit prices are associated with higher total order values.
Larger quantities are associated with higher order values.
Referral sources can be compared based on both customer acquisition and revenue.
Monthly order trends help identify changes in customer demand.
Top-performing products contribute significantly to overall revenue.
Order status analysis helps monitor successful and unsuccessful transactions.

💡 Business Recommendations

Based on the analysis:
Focus marketing investment on high-performing referral channels.
Promote high-performing products through targeted campaigns.
Use bundles and cross-selling strategies to increase average order value.
Monitor monthly order trends for marketing and inventory planning.
Track cancelled and returned orders to identify operational improvements.
